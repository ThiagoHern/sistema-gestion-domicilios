REQUISITOS
----------
1. Java 17 o superior (JDK 17+).
2. MySQL Server 8.0 instalado y encendido (servicio MySQL80).

PASO A PASO (WINDOWS)
---------------------
1. Encienda MySQL: presione Win + R, escriba services.msc, busque MySQL80
   y haga clic derecho -> Iniciar.

2. Haga doble clic en:  ejecutar.bat
   - Ingrese su usuario de MySQL (Enter = root).
   - Ingrese su contraseña de MySQL (Enter = root, o escriba VACIO si no tiene).
   - Responda S para cargar sql\01_BD_SistemaDomicilios_Final.sql automáticamente
     (o ejecútelo manualmente en MySQL Workbench con Ctrl + Shift + Enter).

3. Se abrirá automáticamente el navegador en:  http://localhost:8080

4. (Opcional) Pruebas en Postman:
   Importe  postman\Sistema_Domicilios_Cali.postman_collection.json  en Postman
   o ejecute en PowerShell:
     postman collection run postman\Sistema_Domicilios_Cali.postman_collection.json

(Opcional) Para ejecutar desde el código fuente sin instalar Maven:
  .\mvnw.cmd spring-boot:run
